# Git Integration

Xed-Editor includes built-in support for Git, allowing you to manage your source code directly from the editor.

## Features

- **View Changes**: See a list of modified, added, and deleted files in your repository.
- **Diff View**: Compare the changes in a file with the previous version.
- **Stage/Unstage**: Easily stage changes for your next commit.
- **Commit**: Create commits with custom messages.
- **Branch Management**: View and switch between branches.
- **Visual Indicators**: The file tree shows visual cues for modified files.

## Git Tab

The Git interface is located in a dedicated tab in the side panel.

1. Open the side panel.
2. Click on the **Git** icon (usually a branch symbol).
3. Here you can see the status of your current repository.

## Configuration

You can configure Git settings in:

**Settings -> Git**

- **User Name**: The name used for Git commits.
- **User Email**: The email address used for Git commits.
- **Auto-fetch**: Periodically fetch updates from the remote repository.

::: tip
Ensure that you have a Git repository initialized in your project folder for the Git features to be active.
:::
