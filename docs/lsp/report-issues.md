# Report Issues

If you encounter any issues with the Language Server Protocol (LSP) features in Xed-Editor, such as autocomplete not working, incorrect error highlighting, or server crashes, please follow these steps to report the problem.

## Before Reporting

1. **Check the Logs**: Xed-Editor provides detailed logs for each language server. You can view these by navigating to:
   **Settings -> Editor -> Manage language servers -> [Select Server] -> View Logs**.
   These logs often contain valuable information about what went wrong.

2. **Verify Server Status**: Ensure the server is enabled and its status is "Running".

3. **Check for Updates**: Make sure you are using the latest version of Xed-Editor and that the language server itself is up to date.

## How to Report

Please report issues on our GitHub Issue Tracker.

When reporting an LSP issue, please include the following information:

- **Xed-Editor Version**: The version of Xed-Editor you are using.
- **Language Server**: Which language server is having issues (e.g., Python, TypeScript).
- **File Type**: The extension of the file you were working on.
- **Description of the Problem**: What were you doing, what happened, and what did you expect to happen?
- **Relevant Logs**: Copy and paste the relevant parts of the LSP logs.
- **Sample Code**: If possible, provide a small code snippet that reproduces the issue.
